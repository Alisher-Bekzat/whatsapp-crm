# 📱 WhatsApp CRM - Kanban доска для управления задачами

Система управления задачами с автоматическим парсингом сообщений из группы WhatsApp и Kanban доской для визуального управления статусами.

## ✨ Возможности

- 🤖 **Автоматический парсинг WhatsApp** - парсит сообщения по ключевым словам (флагам)
- 📊 **Kanban доска** - визуальное управление задачами с перетаскиванием
- 🔧 **Динамические колонки** - добавляйте, переименовывайте и удаляйте колонки
- 📝 **Ручное добавление задач** - добавляйте задачи прямо в интерфейс
- 💾 **Сохранение истории** - все изменения хранятся в БД
- 🔄 **Real-time обновления** - данные обновляются автоматически
- 👥 **Совместный доступ** - несколько человек видят одну доску по сети

## 🛠️ Требования

- Python 3.8+
- Chrome браузер (для Selenium)
- pip (менеджер пакетов Python)

## 📥 Установка

### 1. Клонируем репозиторий

```bash
git clone https://github.com/Alisher-Bekzat/whatsapp-crm.git
cd whatsapp-crm
```

### 2. Устанавливаем зависимости

```bash
cd backend
pip install -r requirements.txt
```

### 3. Скачиваем ChromeDriver

Парсер использует Selenium, нужен ChromeDriver:

- Скачайте с https://chromedriver.chromium.org/
- Положите в папку `backend/` или добавьте в PATH

**Или установите через pip:**

```bash
pip install webdriver-manager
```

## 🚀 Запуск

### Запуск Flask сервера

```bash
cd backend
python app.py
```

Сервер запустится на **http://localhost:5000**

## 👥 Многопользовательский доступ (Локальная сеть)

### Как подключить других пользователей?

#### Шаг 1️⃣: Узнайте IP адрес вашего компьютера

**Windows:**
```bash
ipconfig
```
Найдите строку `IPv4 Address` вроде `192.168.x.x`

**Mac/Linux:**
```bash
ifconfig
```
Ищите `inet 192.168.x.x` или `inet 10.x.x.x`

#### Шаг 2️⃣: Запустите сервер

```bash
cd backend
python app.py
```

Вы увидите:
```
🚀 Starting Flask server...
📱 Open http://localhost:5000
 * Running on http://127.0.0.1:5000
```

#### Шаг 3️⃣: Другие люди открывают

Они открывают в браузере:
```
http://192.168.1.100:5000
```

**Вместо `192.168.1.100` подставьте ваш IP из шага 1**

#### Шаг 4️⃣: Все видят одну доску!

- ✅ Задачи синхронизируются в реальном времени
- ✅ Каждые 5 секунд доска обновляется
- ✅ Все видят изменения друг друга

### Пример сценария

```
Компьютер: 192.168.1.100
┌─────────────────────────────────┐
│ Вы открываете:                  │
│ http://192.168.1.100:5000       │
│ (вводите в браузер)             │
└─────────────────────────────────┘

Коллега 1 (телефон/планшет):
│ http://192.168.1.100:5000       │
│ (видит ту же доску)             │

Коллега 2 (другой компьютер):
│ http://192.168.1.100:5000       │
│ (все синхронизировано)          │
```

## 📖 Использование

### 1. Откройте приложение

Откройте браузер и перейдите на http://localhost:5000 (или ваш IP:5000)

### 2. Запустите парсер WhatsApp

- Нажмите кнопку **"▶️ Запустить парсер"**
- Откроется окно Chrome с WhatsApp Web
- **Отсканируйте QR код** своим телефоном
- После загрузки чатов парсер начнёт работать

### 3. Как работает парсинг?

**Флаги (ключевые слова):**

| Флаг | Колонка |
|------|---------|
| "привезли" | Привезено |
| "выгружаю" | Выгрузка |
| "в пути" | В пути |
| "завершено" | Завершено |

**Пример:**
```
Привезли яблоки на склад
→ Создаст задачу в колонке "Привезено"

Иван выгружаю товар
→ Создаст задачу в колонке "Выгрузка"
```

### 4. Управление доской

- **Добавить колонку** - нажмите "➕ Добавить колонку"
- **Переименовать колонку** - нажмите ✏️ на заголовке
- **Удалить колонку** - нажмите 🗑️ на заголовке
- **Добавить задачу** - нажмите "➕ Добавить задачу" в колонке
- **Переместить задачу** - перетащите задачу между колонками (все видят!)
- **Удалить задачу** - нажмите 🗑️ на задаче

## 🔧 Конфигурация

### Изменить флаги и колонки

Отредактируйте `backend/config.py`:

```python
FLAGS = {
    "привезли": "Привезено",
    "выгружаю": "Выгрузка",
    "в пути": "В пути",
    "завершено": "Завершено",
}

DEFAULT_COLUMNS = ["Новая задача", "Привезено", "Выгрузка", "В пути", "Завершено"]
```

### Изменить интервал парсинга

В `config.py`:

```python
PARSE_INTERVAL = 30  # Парсить каждые 30 секунд
```

## 📡 API Endpoints

### Задачи
- `GET /api/tasks` - получить все задачи
- `POST /api/tasks` - создать задачу
- `PUT /api/tasks/<id>` - переместить задачу
- `DELETE /api/tasks/<id>` - удалить задачу

### Колонки
- `GET /api/columns` - получить все колонки
- `POST /api/columns` - создать колонку
- `PUT /api/columns/<id>` - переименовать колонку
- `DELETE /api/columns/<id>` - удалить колонку

### Парсер
- `POST /api/parser/start` - запустить парсер
- `POST /api/parser/stop` - остановить парсер
- `GET /api/parser/status` - статус парсера

### История
- `GET /api/history` - получить историю изменений

## 🐛 Решение проблем

### ChromeDriver не найден

```bash
pip install webdriver-manager
```

Драйвер будет загружен автоматически.

### "WhatsApp Web не поддерживается"

- Убедитесь, что используете Chrome браузер
- Попробуйте обновить Chrome

### Парсер не создаёт задачи

1. Проверьте, что сообщения содержат флаги из конфига
2. Проверьте консоль для ошибок
3. Убедитесь, что WhatsApp Web загрузился полностью

### Другие не видят доску

1. Убедитесь, что вы на одной сети (WiFi)
2. Проверьте IP адрес (команда `ipconfig` или `ifconfig`)
3. Откройте http://[ВАШ_IP]:5000 в браузере другого пользователя
4. Если не работает - проверьте файрвол
